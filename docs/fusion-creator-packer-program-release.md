# Packer: signed managed ProgramDescriptor release

Base: `creator-wave8-base` (`45005ad`). `PackerGameRecipe.program_descriptor` is an optional local-recipe field. With it, the Packer emits GameManifest 1.1 with the descriptor inline and requires the existing Source signing key. The signed SourceIndex remains 1.0 and pins the exact manifest bytes. Existing recipes continue through the 1.0 path. Frozen portable and IPC contracts are unchanged.

This slice supports standalone, redistributable managed directory inputs with an empty component `source_root`. Packer creates their ZIPs from the checked inventory; prebuilt ZIPs are not accepted for inline descriptors. The descriptor determines the mount; conflicting declarations are rejected. Packer hashes all loadable files, compiles the full checked inventory, and runs the planner for every declared profile pair. Other component origins, inheritance and partial archive roots are not implemented in this slice. It uses the existing publication URL behavior; hosting parity is not asserted.

Keep the signing key outside the publication tree and all input components. Packer rejects a key path inside publication output and an exact copy of the supplied key in the checked input inventory, including a renamed copy. Signed builds and verification use private staging outside the publication tree with a protected Windows DACL. The temporary volume must have space for normalization and repacking. The build refuses to retain an indexed inline descriptor in an unsigned update, and `verify` rejects unsigned inline-descriptor releases. These checks are not a general secret scanner or a substitute for an export allowlist.
